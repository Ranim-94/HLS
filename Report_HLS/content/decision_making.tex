

\chapter{Decision Making}

\section{Introduction}

Conditional statements and decision making plays an important role in algorithmic design. In this chapter, we see how an condition statment can be implemented, and what is the corresponding hardware for such a task.

\section{Recap}

Recall that a condition is usually implemented in software as \verb|if-else| as shown in \autoref{fig:conditions:condition_soft}.


\begin{figure}[h]
\centering
\includegraphics[scale=0.35,frame]{Figures/conditions/condition_soft}
\caption{Condition in software}
\label{fig:conditions:condition_soft}
\end{figure}

\begin{itemize}

\item We have some condition define by some boolean expression

\item if the condition is true consequence is selected else the alternative is selected

\end{itemize}

	\item This correspond to a special \verb|if| where we have no  \verb|else| condition

\end{itemize}

\section{Multiplexer}

To impelement conditions using logic gates, usually we use a MUX circuit as shown in \autoref{fig:conditions:MUX}.

\begin{figure}[h]
\centering
\includegraphics[scale=0.65,frame]{Figures/conditions/MUX}
\caption{Multiplexer}
\label{fig:conditions:MUX}

\begin{itemize}

\item In the right hand side, we have the special case MUX where we have 1 select line to select between inputs

\item Then we have the generalize case where we have $m$ select line to select between $n$ inputs

\end{itemize}

\section{Coders}

Now we move to coders circuit, that is encoder and decoder.

Recall that encoder is a circuit which transforms data from one shape to the other for various reason (security,compression,$\cdots$). Decoder does the opposite, that is retreive the original data from the coded data. In other words, encoders and decoders are circuit \tbi{change the forme of the data}.


\begin{figure}[h]
\centering
\includegraphics[scale=0.40,frame]{Figures/conditions/coders}
\caption{Encoder and Decoder}
\label{fig:conditions:coders}
\end{figure}


In general, coders circuit take $n$ input bits and generate $m$ output bits.

\section{Exercice: Leading One}

Now after completing the understanding of coders,MUX and decision making process, we take an exercice to apply these concepts.\\

\underline{Given:} 

Desing a combinational logic circuit that returns the position of leading 1 in an input of 9 bit number. The circuit returns -1 if no 1 exist in its binary representation. Examples are given in \autoref{fig:conditions:example_leading_1}.

\begin{figure}[h]
\centering
\includegraphics[scale=0.40,frame]{Figures/conditions/example_leading_1}
\caption{Some examples for the needed circuit}
\label{fig:conditions:example_leading_1}
\end{figure}

\begin{itemize}

\item Note that by leading 1 we mean the 1 in the MSB position

\item So if we have multiple 1 in the binary representation as in the $\mathrm{1}^\mathrm{st}$ example in \autoref{fig:conditions:example_leading_1}, we return the 1 in the MSB position


\end{itemize}

\newpage
\underline{Solution:}

$\mathrm{1}^\mathrm{st}$ we present the \verb|HLS| code in \autoref{fig:conditions:leading_1_hls}.


\begin{figure}[h]
\centering
\includegraphics[scale=0.40,frame]{Figures/conditions/leading_1_hls}
\caption{HLS code for leading 1 circuit}
\label{fig:conditions:leading_1_hls}
\end{figure}

\begin{itemize}

\item It checks for each bit position in \verb|a| if 1 exist, starting from the MSB position, that is from 8

\item If not, it moves to the next bit poistion using \verb|elseif| statement

\end{itemize}

$\mathrm{2}^\mathrm{nd}$ in \autoref{fig:conditions:leading_1_circuit}, we have the logic circuit representation


\begin{figure}[h]

Some notes regarding \autoref{fig:conditions:leading_1_circuit}:

\begin{itemize}

\item There are 2 logic circuit representation possible in \autoref{fig:conditions:leading_1_circuit}

\item The $\mathrm{1}^\mathrm{st}$ one at the right, uses a MUX and a combinational circuit which gives the select lines for the MUX

	\begin{itemize}
	\item The input for the MUX are the index value of 9 bit binary number from $0 \rightarrow 8$, and -1
	
	\item The combinational circuit takes as input the 9 bit binary number, and provide the select line for the MUX so it can passes the index to the output	
	
	\end{itemize}

\item A $\mathrm{2}^\mathrm{nd}$ representation is shown at the right hand side, uses 4 $\left(\, 2 \, \times \, 1 \,\right)$ MUX. 

	\begin{itemize}
	\item Each MUX determine 1 bit in the 4 binary output
	\end{itemize}

\end{itemize}
