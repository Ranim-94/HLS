

\chapter{Single Cycle Desing}

After introducing the basic idea about sequential circuits in \autoref{chap:d_ff}, now we see some techinques to desing some real world sequential circuits.

The main objectives in this chapter are:

\begin{itemize}

\item Understand single desing technique and how to implement it in \verb|Vitis-HLS|

\item IP centric desing in \verb|Vivado|

\item Investigate circuit signals through RTL co-simulation

\end{itemize}
